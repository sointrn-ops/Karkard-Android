# KARBAN Android 3.0

نسخه اندرویدی مستقل برای ثبت و مدیریت کارکرد.

## امکانات پایه پیاده‌سازی‌شده در این شاخه
- داشبورد خلاصه کارکرد و مساعده
- ثبت چند مساعده و چند مورد اضافه‌کاری در یک روز
- تقویم شمسی و نمای هفتگی
- آرشیو سوابق با جست‌وجو و فیلتر ماه و سال
- گزارش خلاصه عملکرد و جمع مساعده‌های ماه جاری
- تنظیم حقوق بر اساس حقوق ماهانه یا نرخ ساعتی
- محاسبه خودکار اضافه‌کاری با دقت دقیقه و ضریب قابل تنظیم
- اصلاح مستقل دستی مدت و مبلغ اضافه‌کاری
- حفظ محاسبات ذخیره‌شده سوابق قدیمی پس از تغییر تنظیمات حقوق
- پشتیبان نسخه ۲ شامل سوابق و تنظیمات، با پشتیبانی از بازیابی نسخه ۱
- تست‌های واحد برای محاسبات زمان، حقوق و اضافه‌کاری
- ویرایش و حذف رکوردها
- کپی اطلاعات روز قبل
- تم روشن و تیره
- ذخیره محلی رمزنگاری‌شده با AES-GCM و Android Keystore
- خروجی و بازیابی نسخه پشتیبان JSON
- صفحه درباره ما و راه‌های تماس با سازنده
