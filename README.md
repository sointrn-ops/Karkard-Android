# KARBAN — ثبت کارکرد

اپلیکیشن بومی اندروید برای ثبت و مدیریت کارکرد هفتگی.

- نام نمایشی برنامه: KARBAN
- نام برند: KARBAN
- نسخه فعلی: 2.3
- پلتفرم: Android (Kotlin + Jetpack Compose)
- آیکون اختصاصی: `app/src/main/res/drawable/ic_karban_launcher.xml`
- ذخیره‌سازی محلی رمزنگاری‌شده با Android Keystore
- پشتیبان‌گیری و بازیابی اطلاعات با فایل JSON

## دریافت برنامه

فایل APK آزمایشی از بخش **Actions** و آخرین اجرای موفق گردش‌کار **Build Android APK** قابل دریافت است. برای انتشار عمومی و پایدار، نسخه امضاشده باید در بخش **Releases** منتشر شود.

## ساخت

با هر به‌روزرسانی شاخه `main`، گردش‌کار GitHub Actions فایل APK را می‌سازد.
