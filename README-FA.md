# KARBAN — ثبت کارکرد (نسخه ۲.۳)

اپلیکیشن بومی اندروید برای ثبت و مدیریت کارکرد هفتگی با Kotlin و Jetpack Compose.

## مشخصات
- نام برنامه: KARBAN
- نسخه: 2.3 (versionCode 7)
- رابط کاربری بومی Android
- ذخیره‌سازی محلی رمزنگاری‌شده با AES/GCM و Android Keystore
- پشتیبان‌گیری و بازیابی اطلاعات با فایل JSON
- حداقل نسخه اندروید: Android 6.0 (API 23)

## ساخت APK
1. پروژه را در Android Studio باز کنید.
2. اجازه دهید Gradle Sync کامل شود.
3. از مسیر **Build > Build Bundle(s) / APK(s) > Build APK(s)** خروجی بگیرید.

فایل Debug APK معمولاً در مسیر `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## دریافت خروجی GitHub Actions
در مخزن GitHub وارد زبانه **Actions** شوید، گردش‌کار **Build Android APK** را باز کنید و Artifact آخرین اجرای موفق را دریافت کنید.

## نگهداری اطلاعات
اطلاعات برنامه به‌صورت محلی روی گوشی نگهداری می‌شود. پیش از حذف برنامه یا پاک‌کردن داده‌های آن، از بخش پشتیبان‌گیری خروجی JSON تهیه و آن را در محل امن نگهداری کنید. فایل پشتیبان JSON رمزنگاری‌شده نیست؛ آن را محرمانه نگه دارید.

## انتشار
Artifactهای Actions برای آزمایش هستند و ماندگاری محدودی دارند. برای انتشار عمومی، APK نسخه Release باید با کلید امضای پایدار امضا و در بخش GitHub Releases بارگذاری شود.
