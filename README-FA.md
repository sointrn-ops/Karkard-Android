# اپلیکیشن کاربان (نسخه آغازین)

## امکانات فعلی
- شش روز کاری از شنبه تا پنجشنبه
- ثبت تاریخ، اضافه‌کار، مساعده و گزارش روزانه
- ذخیره محلی روی گوشی با Room Database
- آرشیو هفته‌هایی که اطلاعاتشان ذخیره شده
- خروجی PDF
- خروجی CSV سازگار با Excel

## اجرای پروژه
1. Android Studio را نصب و اجرا کنید.
2. از مسیر **Open** پوشه `KarkardApp` را انتخاب کنید.
3. منتظر بمانید Gradle Sync کامل شود.
4. گوشی اندرویدی را با USB وصل کنید و USB debugging را فعال کنید، یا یک Emulator بسازید.
5. دکمه Run را بزنید.

## ساخت APK
از منوی Android Studio:
**Build > Build Bundle(s) / APK(s) > Build APK(s)**

فایل خروجی معمولاً در مسیر زیر ساخته می‌شود:
`app/build/outputs/apk/debug/app-debug.apk`

## نکته‌های نسخه آغازین
- تاریخ به‌صورت دستی وارد می‌شود؛ تقویم انتخاب تاریخ شمسی در مرحله بعد اضافه می‌شود.
- خروجی Excel در این نسخه CSV با کدگذاری UTF-8 و سازگار با Excel است، نه فایل XLSX بومی.
- داده‌ها فقط روی همان گوشی ذخیره می‌شوند. حذف داده‌های برنامه یا پاک‌سازی حافظه برنامه ممکن است آن‌ها را از بین ببرد؛ نسخه پشتیبان‌گیری در مرحله بعد قابل افزودن است.
- شناسه هفته فعلاً بر اساس شماره هفته میلادی ساخته می‌شود؛ در نسخه بعد می‌توان انتخاب دقیق بازه هفته شمسی را اضافه کرد.
